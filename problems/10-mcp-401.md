# `mcp test` says `401 Invalid API Key`

**Why:** The key saved in Hermes is old or has extra characters.

**Fix:**
Copy the key again from Postiz (Settings → API Key → Reveal → Copy), then:
```
hermes -p public config set POSTIZ_API_KEY <the key>
hermes -p public mcp test postiz
```
A good key is 64 characters.

**Watch out:** A 401 means the address is right and only the key is wrong. Good news.
